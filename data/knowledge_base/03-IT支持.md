# IT 支持

本文档汇总常见 IT 问题渠道与自助处理方法。

## 服务渠道

- 工单系统：内网 `it-support.company.com`，提交后自动分配工程师。
- 紧急热线：分机 9111，网络中断、无法登录等影响业务的问题使用。
- 服务时间：工作日 09:00–19:00；非工作时间仅处理 P1 级故障。

## 常见事项

| 问题 | 处理建议 |
| --- | --- |
| 忘记密码 | 自助门户重置，或联系桌面支持 |
| 邮箱异常 | 清缓存后重登，仍不行提交工单 |
| 软件安装 | 通过「软件中心」自助申请 |

## 设备领用

新员工设备由 IT 在入职日发放，离职时须归还并注销账号。外设采购需在资产系统申请。

## 服务级别

- P1（全员受阻）：2 小时内响应。
- P3（个人问题）：1 个工作日内处理。

> 提交工单请附截图与报错信息，可显著加快定位。
